# 上一轮图像端快照

这里保留本次重新上传前、上一轮仓库整理得到的图像端源代码快照。

新上传的 `rtl/new/` 与这份快照在 `ov5640_hdmi`、`connect_component_top`、`connect_8_area`、`coordinate_centroid` 和 `angle_find` 等文件上存在实际内容差异，因此不能把本次变更视为单纯的目录重命名。为避免丢失原始技术资料，本目录保留旧文件的完整内容；它们仅用于版本对照和溯源，不应与当前活动图像端源文件无选择地同时加入同一个工程文件列表。

当前活动图像端位于仓库的 `rtl/` 和 `sim/vision/` 目录。该目录中的文件不代表当前活动实现，也不覆盖根目录下的机械臂工程快照。
