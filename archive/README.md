# Original Project Archive

`CICC_2025_Arm.zip` is the original archive supplied in the repository. Its SHA-256 was recorded before reorganization and is verified unchanged after the move.

The archive contains the complete Quartus project snapshot, generated databases, ModelSim artifacts, backup RTL, Intel/Altera IP, and arm-side source. Selected non-backup RTL, tests, project settings, and IP wrappers were copied into the browsable portfolio layout; the archive is retained so the original snapshot remains available for provenance.
